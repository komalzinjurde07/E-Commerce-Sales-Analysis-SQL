# E-Commerce-Sales-Analysis-SQL
E-Commerce Sales Analysis using SQL

Project Overview

This project focuses on analyzing e-commerce sales data using SQL and MySQL.

The analysis helps understand customer orders, sales performance, product performance, and overall business trends using SQL queries.

Objectives

- Analyze e-commerce orders
- Calculate overall sales performance
- Analyze customer-wise sales
- Identify top-performing products
- Analyze sales by location
- Understand monthly sales trends
- Practice SQL JOINs and aggregate functions

Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- CSV Dataset

SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- Aggregate Functions
- CTE
- Window Functions
- Date Functions

Dataset

The project uses customer and order datasets stored in CSV format.

- "customers-100.csv"
- "orders-100.csv"

Analysis Performed

The SQL queries are used to analyze:

- Total number of orders
- Customer-wise sales
- Product performance
- Location-wise sales
- Monthly sales trends
- Top customers
- Customer sales ranking
